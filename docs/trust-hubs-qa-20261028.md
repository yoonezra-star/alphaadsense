# 운영자 신뢰·허브 경로 검증

작업·로컬 관찰: 2026-10-27~28, 최종 확인일 2026-10-28. 공개 배포 확인 대기.

## 변경 범위

- `domain-and-trust`: 공개 운영 정보·작성/AI 지원·근거·정정 경로를 확인하는 안내로 재작성. 도메인 연식·사업자 표시를 전문성·등록 유효성·광고 승인 인증으로 환산하지 않았다.
- `thin-category-pages`: 독자 작업과 목적지 차이로 허브 유지·통합·보류를 판단. 실제 상황별 입구 변경과 조작 검사를 연결하고 글 수·구성요소 조합을 합격선으로 삼지 않았다.
- 승인·거절 카테고리에 네 가지 상황별 입구를 추가했다. 홈의 기존 비카드형 경로 스타일·아이콘을 재사용했다. 전체 목록·추천 순서는 유지하고 직접 연결·판단표를 해당 목적에 맞게 수정했다. 나머지 네 카테고리에 새 입구를 일괄 추가하지 않았다.
- 모든 가이드의 작성·검토 조직 표시를 소개의 실제 제작 방식으로 연결했다. AI 지원을 공개하고 존재하지 않는 개인 저자·전문가 자격·사람의 전수 검수를 주장하지 않았다. 구조화 데이터의 운영 조직 정보는 유지했다.
- 소개·문의에 실제 목적지 id·초점을 추가하고 운영/제작 방식·민감정보 주의·보관 미정 상태를 연결했다.
- 시작 가이드의 고정 3일 일정과 반복 경로표를 제거했다. 실제 자료·허브 역할·공개/계정 확인 조건을 나눴다. 승인 준비 허브의 운영자 문서 소개도 맞췄다.
- 새 CSS 버전으로 허브 절 이동과 작성자 링크의 표시를 배포한다. 기존 글의 발행일·과거 관찰·화면 날짜는 보존했다. 개정한 두 글·승인/거절 허브·시작/소개/문의/승인 준비 허브·홈 최신 목록·업데이트의 변경일은 2026-10-28이다.
- 개별 본문 32개, 남은 2개. 이는 편집 진행 수이며 승인 점수·확률·결과가 아니다. URL 삭제·병합·리디렉션·DNS·보안·계정·광고/CMP 변경과 실제 메일 발송·재검토 요청은 하지 않았다.

## 근거와 미확인

- 사용자가 제공한 공개 사업자 정보를 소개·문의·푸터와 대조했다. 외부 등록 원장 조회·도메인 소유 증빙·실제 메일 수신·답변 시간 검증은 미실행이다.
- 문의 이메일 보관·삭제 기준은 사용자가 ‘미정’으로 확인한 상태를 유지했다. 실제 보관·계약 검토를 문구 수정으로 해결 처리하지 않았다.
- [사용자 중심 콘텐츠](https://developers.google.com/search/docs/fundamentals/creating-helpful-content?hl=ko), [링크 권장사항](https://developers.google.com/search/docs/crawling-indexing/links-crawlable?hl=ko), [AdSense 자격 요건](https://support.google.com/adsense/answer/9724?hl=ko)을 10월 27일 확인하고 28일 최종 재확인했다.
- 검색 품질 안내를 AdSense 공식 점수표로 쓰지 않았다. 사이트 적합성 세부 도움말 링크는 조회 오류가 있어 세부 조항 확인 완료로 표시하지 않았다. 실제 방문자 성공률·체류·검색·광고 성과는 미확인이다.

## 자동 검사

- 최종 `npm test`: 95개 통과, 실패 0. 공통 작성자 링크 34개·소스/구조화 데이터·표·내부 목적지와 기존 기능 검사 포함.
- 새 가이드의 독립 절·실제/가상/미확인 구분, 도메인/글 수 단정·심사용 메뉴 숨김 안내 제거 검사.
- 승인/거절 입구 각 4개와 실제 목적지·배치 순서·수정일, 다른 카테고리의 입구 미추가, 소개 AI 지원·시작 안내·CSS 검사.
- 63개 HTML·62개 사이트맵 URL·기존 인증 태그·자산·발행일 보존 검사 통과. 미개정 날짜 대상은 `rejection-message-map`으로 변경.
- 홈의 새 수정일 정렬에 따라 두 새 글이 우선한다. 이전 고정 문서 기대값을 실제 개정일 기준으로 보완했다. 이전 본문·화면의 과거 편집 수는 변경하지 않았다.
