# 중복 정리·색인 확인 개정 검사

날짜: 2026-10-27
상태: 로컬 구현·검사 완료, 공개 배포 확인 대기.

## 실제 바꾼 것

- `duplicate-content-cleanup`: 공통 화면·본문/질문 중복·URL 변형 구분. 실제 문서 3묶음의 역할 비교, 대표 문서 선택, 내용 이관과 응답 검사, Pages 미적용 설정 예시.
- `indexing-before-adsense`: 발견·크롤링·색인 분리. 저장된 검사와 실시간 검사, 상태별 대응, 실제 공개 응답과 가상 진단 구분. 색인을 신청 합격선으로 표현하던 문구 제거.
- 두 문서 개별 수정일·출처·관련 글·목차 추가. 등록된 개별 본문은 총 8개, 나머지 26개는 대기.
- 홈 최근 목록·카테고리·검색 제목과 요약 갱신. 이미지 없는 홈 글도 목록의 전체 열 폭을 사용하도록 보완.
- 실제 리디렉션·삭제·보안/DNS/robots 변경·색인 요청·AdSense 재검토는 하지 않음.

## 공개 관찰 기준선

개정 전 일반 HTTPS 요청으로 확인한 결과이며 Google 크롤러/계정 결과가 아니다.

| 대상 | 결과 | 한계 |
| --- | --- | --- |
| 두 기존 글 | 각각 200, 자체 HTTPS canonical | Google 선택 표준 URL·실제 색인 미확인 |
| 두 글의 색인 제어 표식 | robots 메타·X-Robots-Tag 관찰되지 않음 | 다른 시각·요청의 응답 보장 아님 |
| sitemap.xml | 200, XML URL 62개 | 계정 제출·색인 완료 여부 미확인 |
| robots.txt | 일반 허용과 Cloudflare 관리 에이전트별 규칙 함께 존재 | 실제 Google 요청 로그·보안 통과 미확인 |

공개 robots 응답에 Cloudflare 관리 구역이 있으므로 저장소 파일만으로 실제 규칙을 확정하지 않는다. 조사 과정에서 설정을 변경하지 않았다.

## 검사 결과

- `npm test`: 41개 통과. 전체 HTML 63개 인증 태그·스키마·내부 링크·자산, 사이트맵 62개 URL, 기존 주소 보존 확인.
- 두 개정 문서의 자동 반복 본문·일반 진단 표가 사라지고 전용 본문이 출력됨.
- 본문의 `_redirects` 설명이 실제 배포 규칙으로 생성되지 않음.
- 1440px: 중복 정리 목차에서 실제 비교표로 이동. 고정 헤더 아래 목표 소제목 표시.
- 390px: 중복 글 표 영역의 방향키 이동, 파란 초점 표시와 영역 내부 가로 이동 확인. 색인 글 목차 Enter 이동 시 대상 소제목에 초점.
- 320px: 두 문서 페이지 전체 가로 넘침 없음. 중복 글 코드 영역은 내부 폭 279px/콘텐츠 414px로 자체 스크롤.
- 홈의 이미지 없는 두 새 항목: 데스크톱 열 544px 전폭 사용 확인.
- 실제 리디렉션 동작, 계정 색인 상태, 검색 유입·외부 링크, 모바일 실기기·전체 접근성 적합성은 검사하지 않음.
