# 2026-10-27 도구 검증 기록

## 구현 범위

- 기존 `/tools/approval-score/` 주소를 유지하고 점수·신청 준비 판정을 콘텐츠 작업표로 교체.
- URL, 독자 질문, 근거, 중복 후보, 수정 작업, 상태, 확인일 저장·편집·삭제.
- 브라우저 localStorage의 `alphaadsense.content-audit.v1` 키만 사용. 200개 한도와 중복 URL 검사.
- 확인 완료에는 근거와 오늘 이후가 아닌 유효한 날짜가 필요. 이 상태는 승인 결과가 아님.
- 전체 항목 CSV 내보내기. 출력 시 쉼표·따옴표·개행을 처리하고 수식 시작 문자 보호를 적용. 스프레드시트에서 재저장한 파일의 후속 처리를 보장하는 것은 아님.
- 손상 자료는 자동 덮어쓰기하지 않음. 저장 실패 시 현재 탭에만 남았음을 알림. 다른 탭의 변경을 덮어쓰지 않음.
- RPM 글에 계산기 추가. 페이지 RPM·광고 RPM·광고 CTR, USD/KRW 선택, 예시 값·초기화·CSV 제공.
- 계산 입력은 페이지 메모리에서만 처리. 작업표/계산기 입력을 전송하는 네트워크 API 없음.
- 개인정보와 쿠키 안내에 현재 브라우저 저장·삭제·내보내기 범위를 반영.
- Lucide 1.61.0의 아이콘 8개와 라이선스를 빌드에 포함. 외부 CDN 사용 없음.

## 자동 검사

`npm test`: 26개 통과.

- 기존 34개 가이드/62개 사이트맵 주소와 소유권 태그 보존, 로컬 링크/JSON-LD 검사.
- RPM 2, 광고 RPM 1, CTR 0.5% 검산. 0 수입은 허용하며 분모 0, 음수, 정수가 아닌 횟수, 누락값, 비정상 범위, 지원하지 않는 통화는 거절.
- 선택 입력이 없는 경우 미계산과 수치 0을 구분.
- 위험한 URL, 자격 증명 포함 URL, 자기 자신을 중복으로 입력한 경우, 누락/과다 길이와 잘못된 완료 상태 검사.
- JSON 저장 왕복, 손상 자료·버전·개수·중복 ID 검사.
- 저장 권한/용량/삭제 실패 및 다른 탭 변경은 가짜 저장 객체를 사용하는 단위 검사로 검증. 실제 브라우저의 차단 설정은 변경하지 않았음.
- 도구 키 외의 자료는 삭제하지 않는지 확인.
- 모듈이 준비되기 전 폼은 비활성 상태로 제공해 일반 폼 전송을 방지.

## 브라우저 검사

로컬 미리보기, Chromium 기반 인앱 브라우저에서 QA용 가상 URL과 기록만 사용.

- 빈 목록, 내보내기/전체 삭제 비활성 상태 확인.
- 근거·확인일 없이 확인 완료 저장 시 오류 확인.
- 기록 추가, 재로드 후 복원, 편집, 상태 필터와 검색 결과 없음 상태 확인.
- 입력한 `<strong>`이 HTML이 아니라 문자로 표시됨을 확인.
- CSV를 실제 다운로드하고 한국어 열 제목과 입력값을 확인.
- 전체 삭제 취소 시 기록 유지, 확인 후 QA 기록 삭제 확인.
- 계산 예시 결과 2.00 USD/1.00 USD/0.50% 확인.
- 페이지 조회수 0 입력 시 오류, 이전 결과 제거와 CSV 비활성화 확인.
- 계산 CSV 실제 다운로드, 초기화 후 결과 제거 확인.
- 두 도구 각각 1440px/390px/320px에서 페이지 가로 넘침과 잘린 컨트롤 없음. 아이콘 정상 로딩.
