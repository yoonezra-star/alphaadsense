# 2026-10-27 공개 구조 감사 근거

검사 대상: https://alphaadsense.com/
범위: 새 편집/감사 문서 배포 전 공개 화면. 계정 데이터나 실제 사용자 조사는 포함하지 않음.

## 기록한 사실

- 데스크톱 뷰포트 1440×1000: 주요 메뉴 6개, 홈 h2 9개, main 링크 요소 54개, 고유 목적지 30개.
- footer에 사업자 정보와 이메일, 정책/사이트맵/업데이트 링크가 있음. /about/와 /contact/의 직접 링크는 없음.
- 홈 → 거절 → 추천 읽기 순서의 저가치 해결 글 경로로 목표 URL 도달.
- 홈 → 사이트 검색 → '인증' 검색 → 인증 해결 글 경로로 목표 URL 도달. 결과는 2개이며 인증서가 언급된 접근 불가 문서가 먼저 나옴.
- 모바일 390×844: 페이지 가로 넘침 없음. 두 번째 주요 구역의 시작은 문서 상단 기준 약 1275px. 첫 화면에 수치 블록이 길게 이어짐.
- sitemap.xml을 XML 파서로 읽고 URL 62개에 순차 요청: 62개 모두 200 응답, 예외 없음. 이 결과는 콘텐츠 품질이나 광고 승인 검사가 아님.
- [감사 기준 홈 원본](../../public/assets/audit-home-20261027.jpg)은 실제 공개 화면 캡처. JPEG 1425×976.
- [모바일 홈](step3-home-mobile-before.png)은 해당 시점의 화면 기록.
