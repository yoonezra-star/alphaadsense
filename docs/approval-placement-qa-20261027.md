# 승인 후 점검·광고 배치 검증

검사일: 2026-10-27. 공개 배포: 대기.

## 변경 범위

- `after-approval-first-settings`: 사이트/ads.txt/정책·규제/실제 노출 구분, 변경 전 기록, 동의 범위, 공식 미리보기·적용·공개 검사와 복구로 재작성.
- `ad-placement-principles`: 혼동·우발 클릭·콘텐츠 비중 분류, 정적인 가상 배치도, 실제 도구 조작 지점과 상태 변화·키보드·모바일 검사로 재작성.
- 수익화 허브 추천 순서와 직접 연결·판단표를 승인 후 상태→배치→지표 해석으로 정리. 다른 카테고리 추천 순서는 유지했다.
- 기존 URL과 원래 발행일 유지. 개별 본문 24개, 남은 10개. 날짜·배포 진척이 승인 점수나 완료 비율은 아니다.
- 실제 계정·ads.txt 상태·결제·CMP는 조회·변경하지 않았다. 광고 코드·게시자 ID·광고 슬롯을 추가하지 않았고 광고 클릭·활성화·재검토 요청도 수행하지 않았다.

## 공식 자료와 한계

AdSense 사이트 상태·자동 광고 설정·정책 센터 문제 유형·EEA/영국/스위스 동의 관리·게재위치·프로그램 정책, 게시자 콘텐츠보다 많은 광고·유료 프로모션 정책을 확인해 각 글에 연결했다.

ads.txt 별도 가이드는 조회 중 접근 오류가 있어 상세 복사 절차·예시 ID를 작성하지 않았다. 사이트 상태 공식 안내에서 확인 가능한 상태 구분만 사용했다. 인증 CMP를 법률 준수 인증으로 표현하지 않았다. 현재 계정 화면·실적은 미확인이다.

배치도는 직접 작성한 비상호작용 개념도다. 공식 광고 화면·실제 광고·성과 검증이 아니고 오른쪽 배치를 정책 통과 예시로 소개하지 않았다. 실제 도구의 조작 지점은 소스에서 확인했지만 그 도구에 광고를 배치하거나 광고 적용 후 이용을 시험하지 않았다.

## 자동 검사

- 실제/가상/미확인 경계, 상태·동의·미리보기 분리, 광고 코드·인터랙션 없는 개념도 검사.
- 표의 region·caption·행/열 제목, 내부 절 주소 존재, 허브 연결·순서·개별 날짜 검사.
- 63개 HTML, 62개 사이트맵 URL, 기존 인증 태그·자산·내부 링크·구조화 데이터, 발행일 보존 검사 통과.
- 미개정 날짜 보존 검사 대상은 이번에 개정한 배치 글 대신 남은 `traffic-quality`로 변경했다.
- `git diff --check` 오류 없음. 줄바꿈 변환 경고만 표시.
