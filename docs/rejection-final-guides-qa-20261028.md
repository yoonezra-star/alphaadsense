- `low-value-rejection-rewrite-example`: 실제 `thin-category-pages`의 과거 문장과 수정 판단·새 답을 대조했다. 보관 소스 `8492621`의 메뉴 제외·최소 문서 조합 표현을 구현 `30b96da`의 허브 판단 안내와 비교했다. 실제 URL 병합이나 승인 성공 사례로 쓰지 않았다.

- 거절 진단 도구의 저가치·원인 미확인 유형과 공통 안내를 실제 근거 중심으로 맞췄다. 선택과 결과 영역의 접근성 연결·변경 알림을 추가했다. 자동 사이트 분석·원인 확정·데이터 전송 기능은 추가하지 않았다.
- 자료 허브의 직접 경로와 두 글의 제목·설명·검색·최신 목록·업데이트를 맞췄다. 실질적 개정일은 2026-10-28이며 기존 발행일은 보존했다.
