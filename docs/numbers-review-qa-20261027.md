# 글 수 기준·재검토 근거 점검 개정

날짜: 2026-10-27
상태: 로컬 구현·검사 완료. 공개 반영 확인 대기.

## 범위와 역할

- `minimum-content-myth`: 확인한 공식 문서의 적용 범위를 밝히고 공식 요건·작업 목표·개인 사례 구분. 글 수·분량·이미지·방문·기간 주장 대신 조사할 작업을 제시.
- `pre-apply-checklist`: 공개 범위, 확인됨/미완료/미확인, 근거와 한계, 계정 확인과 보류 판단을 설명하는 상세 절차.
- `/checklist/`: 같은 목록을 반복하지 않고 절차·기록 도구·숫자 주장 해석으로 연결하는 입구.
- 기존 주소 유지. 개별 본문 12개, 나머지 22개는 편집 대상. 합격 점수나 승인 준비 완료 비율은 부여하지 않음.
- 기존 글의 ‘대표 글 5개’·‘20분 점검’·색인 완료 조건 제거. 이전 7일 캘린더 대신 구현 당시 빈 작업표 캡처 사용.
- 실제 URL 병합·삭제·리디렉션, 게시자 코드/계정 설정 변경, AdSense 검토 요청은 미실행.

## 확인한 근거

- AdSense 자격 요건·사이트 준비·콘텐츠 안내의 현재 원문. 일률적 글 수/글당 분량/방문자 숫자 합격선을 확인하지 못한 범위로 표현하고 무조건 없다는 보편 명제로 바꾸지 않음.
- 검색의 사용자 중심 콘텐츠 안내는 별도 검색 자료로 표시. AdSense 승인 약속으로 해석하지 않음.
- 현재 사이트 연결 안내의 코드·ads.txt·메타 태그 등을 계정 화면과 대조하도록 설명. 인증 토큰이 공개된 것과 계정에서 확인된 것을 구분.
- 작업표의 저장 범위·상태·개인정보 안내와 새 설명 일치 확인. 타 계정 값이나 예시 게시자 ID를 설치하지 않음.

## 로컬 검사 결과

- `npm test` 48개 통과. 63개 HTML 인증 태그·구조화 데이터·내부 링크·자산, 62개 사이트맵 URL 유지.
- 새 두 글의 개별 본문·날짜·목차·출처·표의 제목/행/열 관계 검사.
- 공개 점검 입구 → 상세 절차, 목차 Enter → 대상 제목 초점 이동 확인. 1440px 제목 상단 약 150px, 390px 약 180px.
- 390px 근거 상태 표: 방향키 이동 시 영역 내부 가로 이동과 초점 표시 확인.
- 320px 두 글과 `/checklist/` 모두 페이지 전체 가로 넘침 없음.
- `/checklist/` → 작업표 이동 후 입력 준비 상태 확인. 사용자 기록은 생성·수정·삭제하지 않음.
- 검사 탭 콘솔 오류 없음. 실기기·전체 WCAG 적합성·계정 검토·실제 사용자 관심은 확인하지 않음.
