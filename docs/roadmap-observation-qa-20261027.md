# 준비 작업 순서·관찰 기록 보강

날짜: 2026-10-27
상태: 로컬 구현·검사 완료, 공개 반영 확인 대기.

## 편집 범위

- 로드맵: 현재 상태별 출발점, 선행 조건과 병행 작업, 내용 이관→공개 확인→계정 판단의 구분. 고정 한 달 준비 부록 제거.
- 관찰 기록: 기존 URL은 유지하고 제목·역할 변경. 실제 저장소 변경과 검사 기록, 가상 장애 해석, 재검사 조건을 구분. 고정 7일 안정화표와 캘린더 이미지 연결 제거.
- 허브·상황별 경로·거절 안내·계획 도구의 해당 링크와 완료 신호를 수정 후 관찰·재검사로 변경. 수정한 정적 페이지 4개의 변경일을 갱신.
- 계획 도구 30일은 내부 편집 예시이며 Google의 준비/대기 요건이 아님을 명시. 카테고리당 임의 글 수 표현도 상황별 다음 단계에서 제거.
- 개별 본문 14개, 나머지 20개 편집 대상. 승인 준비 완료 비율을 부여하지 않음.
- 실제 삭제·URL 병합·리디렉션·계정 설정·검토 요청은 미실행.

## 로컬 검사

- 자동 검사 52개. 전체 63개 HTML 인증 태그·스키마·연결·자산과 사이트맵 62개 주소, 개별 수정일·목차·관련 글·표 구조 검사.
- 1440px 로드맵 목차 Enter → 선행 조건 절 초점 이동, 제목 약 150px. 실제 관찰 링크로 기록 글의 해당 절에 이동.
- 390px 기록 목차 Enter → 실제 관찰 절 초점, 제목 약 180px. 표 방향키 조작 시 영역 내부 가로 이동 확인.
- 320px 두 문서 전체 가로 넘침 없음.
- 계획 도구의 거절 단계 선택 시 새 작업 설명·관찰 기록 링크 확인. Google의 대기 요건이나 7일 완료 판정 없음.
- 거절 안내의 복합 문제 선택 시 공개 결과 재검사·미확인 구분 안내 확인.
- 승인 허브의 기록 링크 → 새 관찰 문서 제목 확인. 검사 탭 콘솔 오류 없음.
- 실기기·보조기술 전체·사용자 반응·계정 상태·검색/광고 결과는 검사하지 않음. 자동 감시나 후속 예약 검사도 만들지 않음.
