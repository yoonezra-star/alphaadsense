## 공개 안내에서 바꾼 범위

- 문의: 사이트 오류·일반 문의 목적을 명시하고 계약·결제 증빙이나 불필요한 개인정보를 보내는 창구로 소개하지 않도록 정리했다. 연락처·정정 경로·답변 보장 없음·보관 미정·실제 발송/수신과의 구분은 유지했다.
- 개인정보: 문의 목적 확인과 Pages Web Analytics 비활성 관찰을 날짜·프로젝트 범위로 명시했다. 일반 요청 관찰을 전체 기록 부재로 확대하지 않았고 실제 로그·계약 검토는 남겼다. 기존 이용자 권리·책임자·작업표 저장/삭제·검색 URL·광고 계획의 구분은 유지했다.
- 쿠키: 비활성 분석 기능 하나와 호스팅/보안 처리를 구분하고 개인정보의 `#hosting-check`로 연결했다. 별도 동의 기능이나 광고·분석 코드를 추가하지 않았다.
- 세 문서만 2026-10-29로 실제 개정일을 갱신했다. 발행일과 34개 가이드의 개정일, 과거 사례/화면 날짜는 보존했다. 개인정보의 2026-10-27 미정 확인은 과거 기록으로 유지했다.
- 새 추적·수집·저장·메일 발송/삭제·광고/CMP·DNS·보안·robots 설정을 구현하거나 변경하지 않았다. 실제 계정 확인·계약 감사·재검토 요청과 구분한다.

## 보관·파기 원칙 초안: 아직 채택되지 않음

일반 문의에 맞춰 운영자에게 다음 원칙을 제시하고 답변을 기다리는 상태다. 이 초안을 확정된 공개 정책으로 올리거나 메일을 삭제하지 않았다.

1. 답변과 필요한 후속 확인이 끝나 처리 목적이 달성되고 불필요해진 개인정보는 지체 없이 파기하는 원칙을 적용한다.
2. 다른 법령에 따른 보존이 필요하면 해당 법적 근거·항목·기간을 확인하고 다른 자료와 분리해 관리한다. 모든 일반 문의를 거래 기록으로 취급하지 않는다.
3. 실제 메일·첨부·보낸 편지·휴지통·복사본/백업의 삭제 가능 범위와 담당·확인 방법을 확인한다. 브라우저 데이터 삭제나 코드 변경으로 메일함이 삭제됐다고 표시하지 않는다.
4. 실제로 채택하고 수행할 수 있는 기준과 절차를 확정한 뒤 관련 안내를 갱신한다. ‘미정’이라고 공개하는 것만으로 보유·파기 의무나 처리방침이 완성되는 것은 아니다.

기본 법령 대조: [개인정보 보호법 제21조](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900078981), 시행 2026-09-11 표시의 원문을 2026-10-29 확인했다. 목적 달성 등에 따른 불필요 정보의 파기, 다른 법령상 보존 예외와 분리 보관을 대조한 것이며 모든 법률·계약 요건 검토나 법률 자문은 아니다. 최초 짧은 법령 URL은 본문 대신 래퍼만 표시해 조문정보 원문으로 다시 확인했다.

## 호스팅 자료의 적용 한계

- [Cloudflare Web Analytics](https://developers.cloudflare.com/web-analytics/about/): 클라이언트 비콘 기반 지표와 프로젝트 비활성 상태를 구분했다. 이것만으로 네트워크/보안 처리가 사라진다고 하지 않았다.
- [Cloudflare 쿠키](https://developers.cloudflare.com/fundamentals/reference/policies-compliances/cloudflare-cookies/): 제품/활성 기능에 따라 달라지는 목록을 현재 사이트의 실제 쿠키 목록으로 일괄 복사하지 않았다.
- [공개 DPA](https://www.cloudflare.com/cloudflare-customer-dpa/): 공개 버전 6.4, 2026-04-03 적용 표시를 확인했다. 운영자의 실제 체결 문서·별도 주문/설정·지역별 법률상 분류를 대조 완료하거나 새로 수락한 것은 아니다.

## 실제 이용자 확인 계획: 아직 실행 결과가 아님

실제 독자가 아래 질문에 답을 찾는지 요청하고 출발점·선택 경로·이해한 답·막힌 이유를 기록한다. 숫자를 채우기 위한 방문·반복 접속·광고 클릭을 요청하지 않는다. 완료 시간이나 참여자 수를 Google의 필수 기준으로 정하지 않는다.

- 거절 안내를 받은 독자: 반복 본문을 어떻게 찾고 실제 편집 사례에서 무엇이 바뀌었는지 설명할 수 있는가?
- 소유권 인증이 막힌 독자: 도메인 속성과 URL 접두어의 확인 방법, 공개 태그와 계정 확인의 차이를 구분할 수 있는가?
- 수익 지표를 읽는 독자: 가상 12 USD·6,000 페이지 조회·12,000 광고 노출에서 페이지/광고 RPM을 구분하고 가상 수익을 실제 성과로 오해하지 않는가?

자동 검사·내부 브라우저 검수는 위의 실제 독자 실험을 수행한 증거가 아니다. 아직 실제 방문자 관심·만족도 개선을 확인한 것으로 기록하지 않는다.
