# 발행 계획·용어집·편집 시간표 검증

검사일: 2026-10-27. 공개 배포: 대기.

## 적용 범위

- `content-calendar-30-days`: 고정 발행 주기 대신 가용 시간·예비 시간·조사/집필/검증/공개 확인의 예산, 가상 초과 사례와 편집 시간표 연결로 재작성.
- `glossary-for-beginners`: 광고 보고서의 개수·분모·단위, 가상 계산과 검색/접근/인증/광고 심사의 차이로 재작성.
- 기존 주소 유지. 개별 본문 22개, 남은 12개. URL 삭제·병합·리디렉션·재검토 신청은 수행하지 않았다.
- 기존 계획 도구에 직접 편집 가능한 시간표 추가. 작업 추가·편집·삭제, 단계별 예상 시간, 가용 시간과 비교, 가상 예시·초기화·CSV 제공.
- 시간표 입력은 현재 페이지 메모리에서만 처리한다. 저장·전송·동기화·자동 발행·예약·계정 제출은 없다. 개인정보·쿠키 안내와 도구·검색 메타데이터를 맞췄다.
- CSS 주소 버전을 변경해 새 스타일 요청 경로를 제공했다. 기존 계산기·작업표의 저장 기능은 변경하지 않았다.

## 자료와 한계

Google AdSense 페이지 RPM·광고 RPM·CPC·광고 CTR·페이지 CTR·페이지 조회·클릭·무효 트래픽, Google 검색 과정·사이트맵·robots·대표 URL과 사용자 중심 콘텐츠 공식 자료를 확인하고 해당 문서에 출처를 연결했다.

수익과 시간 예산은 가상 값이다. 실제 계정 수익·유입·심사 상태나 작업 생산성은 측정하지 않았다. 시간 예산이 맞아도 실제 발행·검증·승인이 완료됐다는 뜻이 아니다. 입력 상한은 도구 처리 범위이며 Google 요건이 아니다.
