# 34개 가이드 편집 처리표

점검일: 2026-10-26

이번 작업은 콘텐츠 역할과 소스 검토를 바탕으로 한 편집 계획이다. 현재 검색 유입·외부 링크·계정 심사 자료를 확인하지 않았으므로 병합 후보는 확정 삭제 명단이 아니다. 각 후보는 대체 문서 완성과 기존 유입 확인 후 처리한다. 모든 기존 주소는 이번 단계에서 유지한다.

1. 7번의 개별 본문과 글별 수정일을 지원하는 생성 구조를 먼저 반영한다.
2. 18번의 사실 오류, 29·33번의 배포/인증 절차를 다음 우선 묶음으로 수정한다.
3. 12·30번의 실제 편집/화면 사례를 작성한다.
4. 나머지 유지·재작성 문서를 개별 편집하고, 대체 문서가 완성된 병합 후보부터 주소 이관을 적용한다.
5. 대표 글만 고친 상태를 사이트 전체 개선 완료로 보고하지 않는다. 재검토 신청은 전체 공개 범위 검증 후 판단한다.
