# 34개 가이드 편집 처리표

점검일: 2026-10-26

이번 작업은 콘텐츠 역할과 소스 검토를 바탕으로 한 편집 계획이다. 현재 검색 유입·외부 링크·계정 심사 자료를 확인하지 않았으므로 병합 후보는 확정 삭제 명단이 아니다. 각 후보는 대체 문서 완성과 기존 유입 확인 후 처리한다. 모든 기존 주소는 이번 단계에서 유지한다.

## 적용 순서

1. 7번의 개별 본문과 글별 수정일을 지원하는 생성 구조를 먼저 반영한다.
2. 18번의 사실 오류, 29·33번의 배포/인증 절차를 다음 우선 묶음으로 수정한다.
3. 12·30번의 실제 편집/화면 사례를 작성한다.
4. 나머지 유지·재작성 문서를 개별 편집하고, 대체 문서가 완성된 병합 후보부터 주소 이관을 적용한다.
5. 대표 글만 고친 상태를 사이트 전체 개선 완료로 보고하지 않는다. 재검토 신청은 전체 공개 범위 검증 후 판단한다.

- 목차 선택 후 해당 제목에 초점이 이동하고, 모바일 표를 키보드로 가로 이동할 수 있음을 확인.

## 2단계 첫 묶음 검증

## 2단계 두 번째 묶음: 2026-10-27

- 12·30번 문서 재작성. 최초 우선 제작 대상으로 정한 6개 글의 개별 본문 적용을 마쳤다. 남은 28개는 계속 편집 대상이다.
- 글쓰기 사례는 실제 RPM 개정의 판단과 검증을 다룬다. 전체 완성 글을 중복 재게시하거나 승인 결과를 주장하지 않는다.
- 구조 감사는 개정 전 홈의 54개 링크/30개 목적지, 실제 메뉴·검색 경로, 사이트맵 62개 URL의 200 응답을 기록했다. 분석/심사 계정과 사용자 조사는 검사하지 않았다.
- 감사 기준 홈 화면을 직접 캡처해 공개 자료에 포함했다. 이미지 형식과 실제 크기 1425×976을 확인해 JPEG와 원본 비율로 제공한다.
- 자동 검사 14개 통과. 문서 2개 각각 1440px/390px/320px에서 페이지 넘침과 잘린 본문 없음, 이미지 정상 로딩 확인.
- 목차 초점 이동과 모바일 표의 키보드 가로 이동 확인.

- 다음은 3단계의 증거 기반 콘텐츠 작업표와 RPM 계산 도구 개선이다. 홈/푸터/검색의 남은 문제는 감사 기록을 기준으로 후속 UI 단계에서 적용한다.
