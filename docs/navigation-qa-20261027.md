# 홈·공통 탐색·검색 개선 검사

검사일: 2026-10-27
상태: 로컬 구현 및 검사 완료. 공개 배포 확인 대기.

## 범위

- 홈을 문제별 출발점 두 개, 실제 개정 가이드 여섯 개, 작업표·계산기로 재구성.
- 최초 감사 기준 본문 링크 54개/목적지 30개/소제목 9개에서 12개/10개/3개로 변경. 개수 자체는 승인 기준이 아니다.
- 공통 푸터 소개·문의 및 상단 검색 링크, 현재 페이지 표시 추가.
- 검색은 제목 일치 우선, 모든 단어 포함, 10개 단위 결과, URL 공유·뒤로가기, 빈 결과·실패·재시도 상태 제공.
- Search Console 인증 태그, 사업자 정보, 기존 34개 글 주소와 62개 사이트맵 URL 보존.

## 로컬 확인

- 1440×1000 전체 홈: 두 열 가이드, 이미지·아이콘 모두 로드, 겹침 없이 표시.
- 390×844·320×720 홈: 전체 가로 넘침 없음. 메뉴 링크 높이 44px, 320px에서는 줄바꿈.
- 홈 검색으로 ‘인증’ 제출: Search Console 해결 문서가 첫 결과.
- ‘애드센스’ 검색: 23개, 첫 페이지 10개 → 다음 10개, 뒤로가기 첫 페이지 복원.
- 빈 검색, 없는 검색어 안내와 검색 상태 초점 이동 확인.
- 키보드 Enter 검색, ‘낮은 가치’ 복수 단어 검색과 건너뛰기 링크의 본문 초점 이동 확인. 고정 헤더 아래 목표가 보이도록 여백 보완.
- 자동 검사 38개 통과. 63개 HTML의 인증 태그·구조화 데이터·내부 링크·자산 경로도 확인.
- 소개 → 공통 푸터 문의 이동, 소개 페이지의 현재 위치 표시 확인.
- 검색 엔진 단위 검사: 다중 단어, 한글 정규화, 전체폭 영문, 긴 설명, 잘못된 URL과 동률 순서.
- 가짜 DOM/응답으로 실패→재시도, 불완전 검색 인덱스 거절, 마지막 페이지·검색 전 입력 변경·이력 복원을 별도 검사.
- 실제 브라우저에서 네트워크 장애를 강제하거나 모바일 실기기를 검사하지 않았다. 전체 WCAG 적합성 인증이 아니다.
