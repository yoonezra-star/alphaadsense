# 탐색·접근 오류 문서 검증

검사일: 2026-10-27. 공개 배포: 대기.

## 변경 범위

- `navigation-issue-fix`: 실패한 행동의 재현 양식, 증상별 수정 위치, 가상 고장 사례, 실제 공개 경로 관찰과 복구 재검사.
- `site-down-unavailable`: DNS/TLS/리디렉션/HTTP/보안 계층 구분, 읽기 전용 확인, 실제 공개 응답, 요청별 보안 근거와 복구 기록.
- 두 글의 기존 반복 본문·옛 추가 설명을 대체했다. 기존 34개 가이드와 사이트맵 62개 주소를 유지했다.
- 진단 도구의 탐색·접근 결과와 연결을 맞췄다. 320px 화면에서 긴 select 항목 때문에 scrollWidth 342px가 된 문제를 발견해 항목명과 공통 select 폭 제한을 수정했다.
- DNS, 보안, 인증서, Search Console 및 AdSense 계정 설정은 변경하지 않았다. 재검토 요청도 하지 않았다.

## 공식 근거

AdSense 사이트 준비·크롤러 안내, Google HTTP 상태·링크 문서, Cloudflare Pages 도메인·Security Events·챌린지 응답 안내, W3C 메뉴·초점 가림 문서를 읽고 각 글의 출처에 연결했다. 확인일은 개별 수정일과 함께 표시한다.

## 개정 전 공개 관찰

한국시간 12:47:24~27 일반 Node GET 요청. 인증서 검증 우회·사용자 에이전트 위장·설정 변경 없음.

| 요청 | 실제 결과 |
| --- | --- |
| HTTP 루트 | 301 → HTTPS 루트 → 200, 홈 제목 |
| HTTPS 루트 | 200, 홈 제목 |
| HTTPS www | 200, 홈 제목. 루트 이동은 관찰되지 않음 |
| 기존 접근 오류 가이드 | 200, 개정 전 제목 |

공개 브라우저에서 홈의 저가치 문제별 입구 → 저가치 글, 그 글의 목차 Enter → `#site-audit`와 해당 제목 초점, 하단 문의 → `/contact/`의 연락 정보 확인. 이메일은 발송하지 않았다.

한 환경의 단발성 응답과 제한된 이용 경로 관찰이다. Google 요청 성공·장기 무장애·방문자 만족·승인 결과를 뜻하지 않는다. www의 주소 통일은 별도 운영 검토이며 이번에 리디렉션을 추가하지 않았다.
