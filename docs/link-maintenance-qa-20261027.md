# 내부 링크·기존 글 갱신 검증 기록

검사일: 2026-10-27. 공개 배포: 대기.

## 변경 범위

- `internal-linking-guide`: 다음 질문·연결 문구·목적지·절 주소·실제 도달 검사로 개별 재작성. 실제 글쓰기 허브의 연결 변경과 설명용 문구 비교를 구분했다.
- `evergreen-content-plan`: 정보 유형별 변경 계기, 유지/부분 수정/재작성/병합 판단, 실제 개정·배포 기록, 날짜·과거 관찰 보존과 공개 확인으로 개별 재작성.
- 기존 두 URL을 유지하며 자동 반복 본문과 옛 추가 설명을 대체했다. 실제 URL 병합·삭제·리디렉션은 적용하지 않았다.
- 계획 도구의 보강형 결과만 근거·연결·수정일·공개 확인 흐름으로 변경하고 두 글·작업표로 연결했다. 다른 계획 유형의 전면 개편은 이번 범위가 아니다.
- 개별 본문 20개, 남은 14개. 편집 진척이지 승인 점수나 준비 완료 비율이 아니다.
- DNS·보안·인증·계정·광고 설정을 변경하지 않았고 재검토를 요청하지 않았다.

## 근거

Google 링크 권장사항, 사용자 중심 콘텐츠, 발행·수정 날짜 공식 문서를 확인하고 각 글의 출처에 연결했다. 실제 과거 바로가기는 `d0c4247`의 생성 소스와 현재 소스를 비교했다. 기존 AI·주제 개정 `5c6dc94`, CSS 주소 보완 `0e21740`과 직전 공개 검증 기록을 갱신 사례로 사용했다.

과거 변경을 이번에 다시 수행했다고 적지 않았다. 실제 방문자의 행동·선택 시간·검색 순위·수익·승인 효과는 측정하지 않았다. 과거 공개 HTTP 응답을 이번에 재측정한 것처럼 날짜를 바꾸지 않았다.
