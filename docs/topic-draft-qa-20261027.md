# 주제 선정·AI 초안 검증 문서 기록

검사일: 2026-10-27. 공개 배포 검증: 대기.

## 적용 범위

- `topic-selection-for-adsense`: 독자 질문, 자료 확보, 기존 글과의 차이, 수요·유지 비용과 작성/조사/병합/보류 판단으로 재작성.
- `avoid-ai-like-writing`: 제목을 AI 초안 검증으로 변경. 주장별 원문 대조·계산·실제 경험 검증, 가상 사례 표시와 발행 보류 절차로 재작성.
- 두 기존 URL을 유지하고 일반 본문·중복 추가 설명을 대체했다. 총 18개 개별 본문, 남은 16개. 편집 진척이지 승인 점수가 아니다.
- 글쓰기 허브의 안내·추천 순서·직접 연결·판단표를 두 글과 실제 편집 사례에 맞췄다. 다른 카테고리의 순서·내용·수정일은 바꾸지 않았다.
- 검색 결과의 두 줄 제목 중심이 링크 영역 밖의 h2 빈 공간이 되는 문제를 320px에서 관찰했다. 검색 결과 제목 링크를 block으로 지정해 중심점도 실제 링크가 되도록 수정했다.
- DNS·보안·인증 태그·계정 상태·광고 설정 변경과 재검토 신청은 하지 않았다.

## 근거와 제한

- Google 사용자 중심 콘텐츠, 생성형 AI 콘텐츠, 검색 스팸 정책과 AdSense 콘텐츠·사용자 환경, 페이지 RPM 정의를 공식 원문으로 확인했다. 출처와 확인일을 각 문서에 표시한다.
- 실제 소스의 ‘경험 기반 판단, 예외 상황, 실패 사례를 넣으면 글이 살아납니다’ 문장을 확인했다. 생성 도구의 판별이나 AI 모델 성능 시험은 하지 않았다.
- 기존 RPM 정의 수정과 가상 데이터 검산을 구분했다. 12 USD/6,000회는 실제 수익이 아니다.
- 주제 비교는 현재 확보 자료에 따른 이번 편집 판단이다. 과거 최초 기획 기록·사용자 선호·키워드 수요 조사로 소개하지 않았다.
- 실제 검색량, 경쟁도, 광고 단가, 계정 방문·수익 자료를 조회하지 않았고 승인 확률·예상 수익을 만들지 않았다.

## 자동 검사

- `npm test`: 61개 통과, 실패 0.
- 새 두 글의 근거/가상/미확인 경계, 구형 개수 권고 제거, 표의 region·caption·행열 제목, 목차 id·초점 대상, 검색 수록과 날짜 검사.
- 글쓰기 허브 추천 순서·직접 연결·수정일과 검색 제목의 연속 링크 영역 회귀 검사 추가.
- 63개 HTML의 인증 태그·내부 링크·자산·구조화 데이터, 사이트맵 62개 URL, 개별 수정일·원래 발행일 보존 검사 통과.
- `git diff --check` 오류 없음. 줄바꿈 변환 경고만 표시.
