## 범위와 판단 한계

- 34개 가이드의 등록·제목·개별 절·관련 문서·출처 목록을 대조하고 본문에서 기계적 반복 후보를 탐색했다. 수익 지표/용어집과 준비 순서/관찰 기록 등 후보의 실제 내용과 역할을 비교했다.
- 여섯 카테고리, 승인 준비 허브, 상황별 다음 단계, FAQ의 현재 생성 소스와 실제 경로를 검토했다. 출처 안내 두 페이지와 필수 문서 공통 부록은 다음 수정 대상으로 남겼다.
- 모든 문장의 정확성·외부 출처 전체·법률/계약·실제 사용자 성과를 전수 검증한 것은 아니다. ‘중복 없음’, ‘전문가 전수 검수’, 내부 90점 달성이나 재검토 준비 완료를 선언하지 않는다.
- 34개 본문 모듈 자체는 이번 단계에서 다시 쓰거나 수정일을 일괄 변경하지 않았다. 기존 사례의 과거 편집 수·관찰일·이미지 날짜도 보존했다.

## 반복 후보 탐색

등록된 intro와 section HTML에서 태그·공백을 제거한 텍스트를 탐색 자료로 사용했다. 렌더링 레이아웃·공통 출처/개정 고지는 제외했다. 60자 이상 문장의 정확 일치와 연속 5어절 집합의 Jaccard 비율을 보조 자료로 계산했다. 한국어 형태소·의미 비교, 외부 웹 표절 검사나 Google의 품질 판정이 아니다.

- 정확히 일치하는 긴 문장 후보는 발견하지 못했다. 문장 분리·문자열 기준으로 놓칠 수 있으며 의미 중복이 없다는 결과는 아니다.
- 34개 문서의 561쌍 중 가장 높은 값은 RPM/용어집: 공통 5어절 구간 19개, Jaccard 약 0.014였다. 비율을 합격선으로 사용하지 않았다.
- RPM 글은 대화형 계산·기간 가중 합산·보고서 비교, 용어집은 빠른 정의·단위·검색/접근 용어 비교가 주된 역할이다. 동일한 수식·가상 예시가 일부 반복되지만 전체 답이 같은 것은 아니므로 이번에는 병합하지 않았다.
- 준비 순서/관찰 기록은 공통 5어절 7개, 약 0.004였다. 선행 조건·병행 작업과 실제 변경 기록의 해석을 구분하고, 과거 수치를 현재 작업 현황으로 오해하지 않게 기존 날짜 문맥을 보존했다.
- 전체 34개 문서의 질문·처리 방침은 [기존 편집 목록](guide-content-inventory.md)에 있다. 관련 주제가 같다는 이유나 이 수치만으로 URL을 삭제·병합하지 않았다.

## 경로 보존과 실제 측정

- 승인 카테고리의 실제 `main a`: 24개→15개. 고유 href 11개는 유지했다. 초기 진행 메시지의 14개는 실측 전 예상값 오류였으며 15개로 정정했다. 링크 감소량은 Google 품질 점수나 이용자 성공률이 아니다.
- 여섯 카테고리 각각 추천 4개와 나머지 문서를 분리해 해당 주제의 모든 문서가 추천/나머지 목록에 한 번씩 나오도록 검사했다. 썸네일과 제목의 같은 카드 링크, 상황별 직접 절과 전체 문서의 서로 다른 역할은 이 목록 검사와 구분한다.
- 기존 34개 가이드·62개 사이트맵 URL·63개 HTML·인증 태그·발행일을 유지했다. URL 이전·삭제·noindex·리디렉션·DNS·보안·광고/CMP·계정 변경은 하지 않았다. 재검토를 요청하지 않았다.
- 승인 준비 허브의 실제 빈 작업표 화면 1425×976을 재사용했다. 2026-10-27 구현 당시 화면이며 고정 일정·승인 점수로 제시하지 않았다.
